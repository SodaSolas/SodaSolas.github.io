# SodaSolas Personal Site

Persona 3 Reload–inspired personal site with Wiki categories and GitHub links.

## Local

Open `index.html` in a browser, or:

```powershell
cd E:\soda-site
npx --yes serve .
```

## Structure

- `index.html` — home
- `wiki/` — documentation categories (Projects / Notes / Guides / About)
- `assets/` — CSS & JS
