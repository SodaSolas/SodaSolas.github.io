2. 模块结构

main.gd          输入、热区调度、对话生命周期
player.gd        CharacterBody2D 点目标移动
hotspot.gd       Area2D + dialogue_start
DialogueRunner   图遍历 / 被动 / 主动检定
CheckDef         DC、红白、概率、掷骰
GameState        Autoload：技能、修正、旗标、白检锁
dialogue_ui.gd   日志、选项按钮、掷骰条

运行时关系：热区 → main 走到点 → DialogueRunner.load_graph → 信号驱动 UI；检定读写全部走 GameState。

3. 移动与热区

3.1 点地移动

  • player.go_to(world_pos, running)：每帧朝目标归一化速度；距离 < 6 触发 arrived。
  • 左键空白地：移动；双击或 Shift：run_multiplier（默认 1.65）。
  • 相机挂在 Player 下的 Camera2D，无独立跟随平滑（后续可加）。

3.2 热区交互

  • 热区 input_event 左键 → interacted → 设 _pending_hotspot 并 go_to 热区位置。
  • 已够近（< 48）立刻开对话；否则等 arrived 再 _begin_hotspot。
  • dialogue_start 导出字段可覆盖图入口节点；E 键找最近热区（64 半径）。
  • Tab / highlight 动作提高热区视觉透明度（无轮廓描边管线）。

3.3 输入冲突

对话中 _in_dialogue 挡掉地图点击。结束时用一次性「结束对话」按钮关 UI，避免误点地面。

4. 对话图（JSON）

单文件图：start + nodes[id]。节点字段：

字段含义
speaker / text主台词
passives[]进入节点时先滚的被动插话
options[]选项；可带 check / require / set / next|success|failure
set_on_enter进节点写旗标
end无选项收束
 
{
  "id": "bluff",
  "text": "[Masque] Bluff…",
  "check": {
    "id": "masque_bluff_revek",
    "skill": "masque",
    "difficulty": 11,
    "kind": "active",
    "retry": "white"
  },
  "success": "revek_bluff_ok",
  "failure": "revek_bluff_fail"
}

require：选项可见条件（对旗标等值）。set：点选后写旗标。next：无检定跳转；有检定用 success / failure。

5. 检定系统

5.1 被动 vs 主动

类型触发判定失败后果
Passive进节点，插在主台词前effective(skill) >= difficulty（无骰）静默不插话
Active点选项2d6 + effective ≥ DC；天然 12 必成按红/白锁选项

5.2 红检 / 白检

  • White：失败 → lock_white(id)，选项禁用；加点（技能名出现在 check id）或剧情旗标（如挖到弹壳）可 unlock_white。
  • Red：失败 → red_fail_{id} 永久锁（本原型无重置）。
  • UI 显示预估成功率：枚举 36 面 2d6，按 need = DC - effective 统计；DC 极高时仍按「仅双六」约 3% 地板。

5.3 公式

total = d1 + d2 + skill + modifier
success = (d1+d2 == 12) or (total >= difficulty)

6. 全局状态（GameState）

  • 四属性桶 → 技能表（含 logic / empathy / perception 等，演示未全用）。
  • modifiers：衣物/线索类扁平加成（如读传单给 Chronicle +1；弹壳给 Masque +1）。
  • flags：剧情布尔；white_check_locks：白检锁表。
  • 演示按钮循环：先加 Masque 到 5，再加 Perception——用于手工解锁白检。

7. 已知技术问题 / 债

#问题现状建议
1地面点击与热区抢输入热区先 emit；空白才移动。快速连点可能取消 pending点击射线优先热区，或短冷却
2无 Navigation直线移动，遇 StaticBody 会卡住NavigationAgent2D + 可行走多边形
3被动无骰、无「差一点」阈值硬切可选被动也 2d6，或显示未通过技能灰字
4白检解锁靠 id 子串匹配技能名check_id.find(skill_id)显式 unlocks_on_skill 字段
5对话结束关 UI 用按钮重绑_on_dialogue_end 拆连接再绑 close专用 Close / 状态机
6多行被动瞬时塞进日志无逐条确认队列 + 点击推进（更接近 DE）
7场景占位美术色块 Polygon / LabelTileMap / 精灵层；Y-sort
8单 JSON 全局图热区只切 start 节点分文件 / 资源 Resource；对话包热加载
9红检不可重置旗标永久调试清档；或「思想」类间接重开
10概率文案与天然 12显示 % 与实际「双六必成」边界需对齐UI 注明 critical

8. 后续方向（优先级粗排）

  1. 被动/主动统一推进队列（技能先说话，再 NPC）。
  2. Navigation2D + 障碍，避免穿模卡住。
  3. 检定定义改 Resource / 表驱动，去掉 id 子串解锁。
  4. 最小存档（技能、旗标、白锁、红败）。
  5. 地图分层与氛围（雾、远景视差）——内容向，不挡系统验证。
