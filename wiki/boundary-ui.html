1. 和传统 ADV 的差异

维度常见 ADV《边界震荡》
主对话底部固定文本框 + 名字条浮动气泡，锚在说话立绘附近
底部区域承载全部台词仅旁白 / 说明性文字
画面全屏背景 + 立绘层左 / 中 / 右 三槽位，各自独立推进
点击逻辑全局「下一句」可按区域分别翻页 / 切画面

本质：演出层（三栏）与文本层（双通道）解耦，而不是「一个 TextBox 管所有事」。

2. 画面分层

┌─────────────────────────────────────────┐
│ CanvasLayer: UI（气泡、旁白栏、系统键） │
├─────────────────────────────────────────┤
│ Stage: 三区域演出层（左 | 中 | 右）     │
│   每槽：背景/插画/立绘/特效/局部 CG…    │
├─────────────────────────────────────────┤
│ 全局：色调、颗粒、黑白 shader、转场     │
└─────────────────────────────────────────┘
  • 背景为预渲染 3D 场景（非实时 3D 关卡），每槽或全屏可换静态图 / 序列帧 / CG。
  • 三区域是三个独立 Stage Slot，可分别换内容、做转场，互不绑定完成状态。

3. 双通道文本系统

3.1 A. 角色对话 ― 浮动框（主通道）

  • 定位依赖立绘，不是屏幕固定 Y 坐标。
  • 流程：脚本指定 speaker + slot(left|center|right) → 立绘显示/更新 → 按锚点算气泡 position → 换说话人时气泡迁移或淡出再淡入。
  • 概念公式：Bubble.position = slot.transform × figure.anchor("speech") + offset
  • 名字、正文、CTC 均在气泡节点内；多角色同屏时，气泡挂当前说话者。

3.2 B. 底部栏 ― 旁白（副通道）

  • 固定在屏幕下方，不承担角色对白。
  • 用途：环境描写、内心独白、时间跳转、章节提示、说明书式叙述。
  • 与主通道可并行：上方三栏继续播立绘/CG，下方横条滚旁白。

4. 三区域独立推进

可理解为 3 条并行的 Presentation Track：

左槽 (L)     中槽 (C)     右槽 (R)
输入 stage[l]  stage[c]     stage[r]
状态 {bg, figure, fx}  {...}  {...}
推进 advance(l)? advance(c)? advance(r)?
情况行为
仅一句对白，绑定中槽只更新 C 的气泡；L/R 不动
左槽切 CG，右槽继续对话L fade 换图；R 气泡照常打字
脚本标记 advance:left仅左槽切下一画面；其它槽冻结
旁白行底部栏打字；三槽可不动或后台 slow pan

「下一句」不是全局单一 step，而是带 targets: [L,C,R,narration] 的分发式指令。

4.1 脚本概念模型（推测）

- say:
    speaker: 奇尔希姆
    slot: right
    text: "……"
- stage:
    left: { image: cg_facility.png, transition: fade }
    advance: left
- narration:
    text: "戒严令下的米拉纳尔克，夜雾很浓。"
    advance: narration

5. Godot 运行时模块（推测）

模块职责
StageDirector管理 L/C/R；set_slot / advance_slot
FigureInstance立绘 + 锚点 + 差分/嘴型
FloatingDialogue气泡 UI；挂 Figure/槽位；打字机、CTC
NarrationBar底部 PanelContainer + RichTextLabel
LineInterpreter解析脚本行 → 分发 dialogue / narration / stage
InputRouter点击时按 pending track 消费输入
TransitionPlayer每槽独立 tween / shader 转场

输入路由优先级（推测）：打字未完成 → 先 complete；旁白 pending → 完成旁白；单槽 advance 标记 → 只推进该槽；多路并行按 priority / focus track 排队。

6. 最小数据结构（复刻参考）

Line:
  kind: say | narration | stage | wait | sfx
  targets: [left, center, right, narration]
  await: [left, ...]

SlotState:
  background, figure, overlay, transition

FigureState:
  texture, position, anchors: { speech: Vector2 }
